# Study dataset

The dataset is synthetic and generated by this project. It contains 24 development
and 120 held-out base games with disjoint final rule sets. Each base has one
`seeded` episode and four `order` episodes, for 720 JSONL records. The study selects
`development`/`order`: 96 conversations, 24 in each order.

| File | Contents |
| --- | --- |
| `episodes.jsonl` | One episode per UTF-8 JSON line |
| `development-games.txt` | Readable games and private reference paths |
| `audit-sample.jsonl` | 12 held-out games selected for human quality review |
| `manifest.json` | Seed, file hashes, validation counts, and audit status |

| Episode field | Meaning |
| --- | --- |
| `episode_id`, `base_id` | Unique conversation and shared base-game identity |
| `split`, `track`, `order` | Development/test; seeded/order; original/reverse/random_1/random_2 |
| `family`, `final_set_id` | Interaction family and final rule-set identity |
| `initial` | Neutral starting string used once |
| `rules` | Eight rules in disclosure order, preserving rule IDs |
| `reference_outputs`, `witness` | Private satisfiability examples, never required model answers |
| `reference_challenges`, `reference_certificates` | Private example-path interference evidence |

Rule fields are `id`, `kind`, `value`, `op`, and optional `count`/`position`.
Positions are one-based. Passwords contain 1–32 ASCII letters, digits, or `!_-()[]`.
Matching is case-sensitive. Reference paths are private validation material and do
not determine the model's actual trajectory or interference label.

Regenerate separately with:

```sh
uv run --locked python -m passgame.generate --seed 20261024 --output outputs/generated-data
```

Compare file hashes with the supplied manifest. Generation leaves the human audit
pending. Follow [audit instructions](../docs/audit-instructions.md) before held-out
model evaluation. Dataset and bootstrap seeds are separate.
